# 🛡️ Visual Novel about Information Security

Визуальная новелла, посвящённая вопросам **информационной безопасности, доверия к информации в интернете и цифровой гигиены**.  
Проект разработан в рамках дипломной работы и сочетает **сюжет, выборы игрока и интерактивные мини-игры**, реализованные на Python внутри движка Ren’Py.

🎓 **Дипломная работа** — оценка *«отлично»*  
🎮 **Статус:** завершён, версия 1.0, полностью играбелен

---

## 🧠 Идея проекта

Игра в доступной форме поднимает вопросы:
- доверия информации в сети,
- социальной инженерии,
- базовых принципов личной информационной безопасности,
- последствий необдуманных цифровых решений.

Игрок принимает решения, которые **влияют на развитие сюжета и финал игры**.

---

## 🎭 Жанр и особенности

- Визуальная новелла
- Сюжетные развилки
- **4 различных концовки**
- Встроенные мини-игры
- Музыкальное сопровождение
- Интерфейс, стилизованный под взаимодействие с компьютером и смартфоном

Проект ориентирован на **обучение через интерактив**, а не на сложность или реиграбельность.

---

## 🎮 Мини-игры и интерактив

В игре реализованы несколько полноценных мини-игр, написанных на Python:

### 🔢 2048
- Полная реализация логики игры
- Подсчёт очков
- Обработка окончания игры
- Управление с клавиатуры
- Отрисовка через Ren’Py `screen`

### 🧱 Tetris
- Классическая механика тетрамино
- Вращение фигур
- Очистка линий
- Система уровней и очков
- Реализация игрового цикла без сторонних библиотек

### 🐍 Snake
- Движение по сетке
- Рост змеи
- Ускорение со временем
- Проверка столкновений
- Управление с клавиатуры

### 💻 Симуляция пользовательской среды
- Экран «компьютера»
- Почта, браузер, антивирус
- Сюжетные события, связанные с вирусами и загрузками
- Интерактивные сценарии социальной инженерии

### ❤️ Механика «приложения для знакомств»
- Экран с лайками/дизлайками
- Используется как сюжетный инструмент
- Иллюстрирует вопросы доверия и приватности

## 📁 Структура проекта (обобщённо)

- `script.rpy` — основной сюжет и диалоги
- `screens.rpy` — интерфейсы и мини-игры
- `options.rpy` — базовый файл для настроек
- Python-классы для логики игр (2048, Tetris, Snake)
- Медиа-ресурсы (графика, музыка)

## ▶️ Запуск

1. Установить Ren’Py
2. Скопировать репозиторий
3. Открыть проект в Ren’Py Launcher
4. Запустить игру
